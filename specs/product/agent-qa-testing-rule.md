# Agent QA 测试规则规范

## 目标

为使用 Cursor 和 Agent QA 的软件团队提供一条可复用的中文项目规则，指导代理从测试执行、证据收集、失败分类到范围受控的修复。

## 使用场景

- 用户明确要求使用 Agent QA 测试 Web 或移动端应用。
- 仓库已经包含 Agent QA 工作区或 MCP 配置。
- 团队需要区分产品缺陷、测试缺陷、环境问题和证据不足的结果。

## 功能要求

1. 规则必须引用 Agent QA 的公开仓库作为权威来源。
2. 规则必须使用真实的 MCP 启动命令 `agent-qa mcp`，不得虚构命令参数。
3. 规则必须要求优先执行范围最小的相关测试，并记录截图、跟踪、控制台或网络证据。
4. 规则必须在修改代码前完成失败分类。
5. 规则必须限制破坏性操作、生产数据使用和无依据的断言弱化。
6. 规则必须使用中文，并附带面向使用者的 README。
7. 中英文规则索引必须同步增加该资产。

## 验收标准

- 新规则位于 `docs/rules/general/agent-qa-testing/.cursorrules`。
- 规则文件不少于 500 字节，包含角色、工作流、常见错误规避和结果报告要求。
- `docs/rules/general/agent-qa-testing/README.md` 说明适用范围和使用方式。
- 规则总数和通用分类计数由站点事实生成脚本更新。
- `npm run check` 通过。
