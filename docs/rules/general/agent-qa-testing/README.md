# Agent QA 测试规则

这条 `.cursorrules` 规则用于在 Cursor 中操作 [Agent QA](https://github.com/vostride/agent-qa)，覆盖自然语言 Web 与移动端测试、证据收集、失败分类和范围受控的修复。

## 适用场景

- 项目已经配置 Agent QA 工作区或 MCP 服务器。
- 用户希望验证可观察的端到端行为。
- 测试失败后需要判断问题来自产品、测试或环境。
- Agent QA 提出自愈变更，需要确认变更没有削弱原始意图。

## 使用方式

1. 将 `.cursorrules` 文件复制到项目根目录。
2. 在 Cursor 中打开项目，并确认项目现有的测试说明和 Agent QA 配置。
3. 如使用 MCP 集成，服务器命令为 `agent-qa mcp`。
4. 提交具体的用户行为和目标环境，让代理从范围最小的相关测试开始。

## 规则重点

- 先测试和收集证据，再修改代码。
- 把失败分类为产品缺陷、测试缺陷、环境问题或证据不足。
- 避免生产凭据、付款和破坏性操作。
- 对自愈建议进行人工意图检查。
- 用完成的执行结果、截图、跟踪和日志支持结论。
